**********************************
amazon.ai.bedrock_agentcore_memory
**********************************

**Manage Amazon Bedrock AgentCore memories**


Version added: 2.0.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- Creates, updates, and deletes Amazon Bedrock AgentCore memories.
- Manages the memory settings, its memory strategies, indexed keys, namespace keys, stream delivery and tags.
- Memory strategies are declared as the complete desired set. Strategies are added, modified and deleted to match it.



Requirements
------------
The below requirements are needed on the host that executes this module.

- python >= 3.9
- boto3 >= 1.39.7
- botocore >= 1.39.7

Notes
-----

.. note::
   - The IAM actions are bedrock-agentcore:CreateMemory, bedrock-agentcore:GetMemory, bedrock-agentcore:ListMemories, bedrock-agentcore:UpdateMemory, bedrock-agentcore:DeleteMemory, bedrock-agentcore:ListTagsForResource, bedrock-agentcore:TagResource and bedrock-agentcore:UntagResource.
   - iam:PassRole on the role may also be needed when O(memory_execution_role_arn) is set.
   - When O(encryption_key_arn) is set, the caller needs kms:CreateGrant, kms:Decrypt, kms:DescribeKey, kms:GenerateDataKey, kms:GenerateDataKeyWithoutPlaintext and kms:ReEncrypt* on the key, through the bedrock-agentcore service.
   - Some options need a later botocore release than the one in the requirements, as noted on each option. The module fails with the required version when such an option is set with O(state=present).
   - An omitted option leaves the matching setting of an existing memory unchanged, so a setting cannot be removed by omitting it.
   - A memory managed by another resource, reported in RV(memory.managed_by_resource_arn), can only have its strategies changed or be deleted through that resource. The module fails instead.
   - **Caution:** For modules, environment variables and configuration files are read from the Ansible 'host' context and not the 'controller' context. As such, files may need to be explicitly copied to the 'host'.  For lookup and connection plugins, environment variables and configuration files are read from the Ansible 'controller' context and not the 'host' context.
   - The AWS SDK (boto3) that Ansible uses may also read defaults for credentials and other settings, such as the region, from its configuration files in the Ansible 'host' context (typically ``~/.aws/credentials``). See https://boto3.amazonaws.com/v1/documentation/api/latest/guide/credentials.html for more information.

Examples
--------

.. code-block:: yaml

    - name: Create a minimal memory
      amazon.ai.bedrock_agentcore_memory:
        name: "my_memory"
        event_expiry_duration: 30

    - name: Create a memory with a semantic strategy and a custom override strategy
      amazon.ai.bedrock_agentcore_memory:
        name: "my_memory"
        description: "Memory for my agent"
        event_expiry_duration: 90
        memory_execution_role_arn: "arn:aws:iam::123456789012:role/my-memory-role"
        memory_strategies:
          - semantic_memory_strategy:
              name: "facts"
              description: "Extracts facts from conversations"
              namespace_templates:
                - "/strategies/{memoryStrategyId}/actors/{actorId}"
          - custom_memory_strategy:
              name: "product_facts"
              configuration:
                semantic_override:
                  extraction:
                    append_to_prompt: "Focus on facts about products the user owns."
                    model_id: "anthropic.claude-3-haiku-20240307-v1:0"
                  consolidation:
                    append_to_prompt: "Merge facts about the same product."
                    model_id: "anthropic.claude-3-haiku-20240307-v1:0"
        tags:
          environment: "dev"

    - name: Stream memory records of an existing memory to a Kinesis data stream
      amazon.ai.bedrock_agentcore_memory:
        name: "my_memory"
        memory_execution_role_arn: "arn:aws:iam::123456789012:role/my-memory-role"
        stream_delivery_resources:
          resources:
            - kinesis:
                data_stream_arn: "arn:aws:kinesis:us-east-1:123456789012:stream/my-stream"
                content_configurations:
                  - type: "MEMORY_RECORDS"
                    level: "FULL_CONTENT"

    - name: Stop streaming memory records
      amazon.ai.bedrock_agentcore_memory:
        name: "my_memory"
        stream_delivery_resources:
          resources: []

    - name: Delete a memory
      amazon.ai.bedrock_agentcore_memory:
        name: "my_memory"
        state: absent
